# Semana 01: Lenguaje Matemático y Conjuntos

## 📋 Objetivos de Aprendizaje

Al finalizar esta semana, el estudiante será capaz de:

- [ ] **Dominar la notación matemática**: Utilizar correctamente símbolos, cuantificadores y conectivos lógicos
- [ ] **Trabajar con conjuntos**: Definir, operar y relacionar conjuntos usando notación formal
- [ ] **Aplicar lógica proposicional**: Construir y evaluar proposiciones matemáticas complejas
- [ ] **Demostrar proposiciones básicas**: Utilizar métodos de demostración directa, contraposición y reducción al absurdo

## 🔧 Prerrequisitos

### Conocimientos Previos Necesarios:
- **Aritmética básica**: Operaciones con números naturales, enteros y racionales
- **Álgebra elemental**: Manipulación de expresiones algebraicas simples
- **Lógica intuitiva**: Comprensión básica de "si...entonces", "para todo", "existe"

### Semanas Relacionadas:
- **Semana 02**: Números Reales - Utiliza la notación de conjuntos
- **Semana 03**: Introducción al Análisis - Requiere dominio de cuantificadores

- **Comprensión teórica** (40%): Dominio de conceptos y definiciones de conjuntos y lógica

- **Razonamiento** (20%): Justificación lógica y construcción de demostraciones simples

## 📝 Notas Importantes

> **💡 Consejo de Estudio**: La notación matemática es como un idioma nuevo. Practica escribir y leer expresiones matemáticas en voz alta para familiarizarte con los símbolos.

> **⚠️ Atención**: Distingue claramente entre "∈" (pertenencia) y "⊆" (inclusión). Son conceptos fundamentalmente diferentes que se confunden frecuentemente.
